FinanceControl
Aplicativo de controle financeiro pessoal desenvolvido em Python, com foco no gerenciamento de receitas e despesas, validação de dados e geração de relatórios financeiros.
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Sobre o projeto
O FinanceControl é um projeto desenvolvido com o objetivo de facilitar o acompanhamento das finanças pessoais, permitindo registrar despesas, calcular gastos e visualizar o saldo disponível.
O projeto também tem como objetivo aplicar conceitos de programação Python, organização de código em módulos e testes automatizados.
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Funcionalidades
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
*Cadastro de salário.
*Registro de despesas fixas.
*Registro de despesas extras.
*Validação de entradas numéricas.
*Cálculo do total de despesas.
*Cálculo do saldo final.
*Identificação da situação financeira.
*Geração de relatório financeiro.
*Testes automatizados.
